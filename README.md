# 🍳 KuchennyPlan

Planer posiłków dla dwóch osób z różnymi celami kalorycznymi.

## Funkcje

- **Plan dnia** — podgląd dzisiejszych posiłków z podsumowaniem kalorii
- **Plan tygodnia** — generowanie jadłospisu na cały tydzień
- **Spiżarnia** — lista produktów w domu, filtrowanie po kategoriach
- **Zamiana posiłków** — jeśli danie nie odpowiada, znajdź zamiennik o podobnych makrach
- **Nawodnienie** — tracker wody z przypomnieniami
- **Wspólne gotowanie** — opcja gotowania razem lub osobno
- **Makroskładniki** — białko, tłuszcze, węglowodany, błonnik w każdym posiłku
- **Sprzęt** — wsparcie dla Air Fryer i Thermomix TM6 (przepisy dedykowane)
- **PWA** — działa offline, można dodać do ekranu głównego telefonu

## Dla kogo

- Renata: 1600 kcal/dzień
- Mąż: 2100 kcal/dzień

## Jak uruchomić

Otwórz `index.html` w przeglądarce. Wszystkie dane zapisują się lokalnie w `localStorage`.

## Technologie

- Vanilla JS — zero zależności
- localStorage — prywatność, dane nie opuszczają urządzenia
- PWA — offline, instalacja na telefonie
